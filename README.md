# 🍔 Food Munch - Responsive Restaurant Website

A modern, fully responsive restaurant website built with HTML, CSS & Bootstrap. Clean design, smooth animations, and mobile-friendly.

🔗 **Live Demo:** https://srija-ai-developer-19.github.io/Food_munch_responsive/

![Food Munch Banner](https://i.imgur.com/8Km9tLL.png)

## ✨ Features

- 📱 100% Responsive - Works on Mobile, Tablet & Desktop
- 🎨 Modern UI with Bootstrap 5
- 🔄 Smooth Scroll Navigation
- 🍽️ Sections: Home, Why Choose Us, Explore Menu, Delivery & Payment, Thank You
- ⚡ Fast Loading & Clean Code
- 🎯 Interactive Buttons (View Menu, Order Now)

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling & Animations
- **Bootstrap 5** - Responsive Grid & Components
- **Font Awesome** - Icons

## 📸 Sections

1.  **Banner** - Get Delicious Food Anytime
2.  **Why Choose Us?** - Food Service, Fresh Food, Best Offers
3.  **Explore Menu** - Non-Veg, Veg, Soups, Fish, Desserts
4.  **Healthy Food** - Fresh, Healthy, Organic
5.  **Delivery & Payment** - Fast Delivery
6.  **Thank You** - Gift Vouchers
